Boot Block: What’s Before the Superblock? Link to heading

  • The first block of many filesystems may contain enough startup code for an OS to boot.
  • xv6 keeps a block for this, for convention, but it does not use it. So, it’s reserved and empty, with the superblock starting at block 1 (the second block).
